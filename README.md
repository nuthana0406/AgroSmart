# AgroSmart 🌱

AgroSmart is a smart agricultural e-commerce platform designed to help farmers
access trusted seeds, fertilizers, pesticides, farming services, weather
information, and modern farming techniques.

## Live Prototype

https://grow-unselfish-smart-yield.base44.app

## Features

- Trusted agricultural products
- Seeds and fertilizers marketplace
- Smart farming techniques
- Weather information
- Drone spraying services
- Hydroponics
- Soil testing
- Drip irrigation
- Farm machinery rental
- Shopping cart
- Service booking
- Farmer account and orders
- English, Telugu and Hindi language support
- Farmer-friendly interface

## Technology

- React
- JavaScript
- Tailwind CSS
- Base44
- React Router
- Lucide React

## Project Objective

The main objective of AgroSmart is to provide farmers with a simple and
accessible digital platform for purchasing agricultural products and accessing
modern farming services.
